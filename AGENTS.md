# Photos

`photos-src/` holds the full-size originals; `public/photos/` holds the WebP the
site serves, generated by `npm run photos` (which `predev`/`prebuild` run for
you). Never add an image straight to `public/photos/` — put it in `photos-src/`
and let the script size and encode it. See `scripts/optimize-photos.mjs`.

# Fonts

`font/` holds the full families; `fonts-web/` holds the subset woff2 the site
loads, generated by `npm run fonts`. Only the weights the components actually
render are built, so adding a `font-semibold` anywhere means adding that weight
to both `scripts/optimize-fonts.mjs` and `lib/fonts.ts`.
